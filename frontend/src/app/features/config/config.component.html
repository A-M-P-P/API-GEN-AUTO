Ce que ce mécanisme ne fait pas

  • Le port d'écoute et l'adresse réseau appartiennent au serveur d'application. Sur WebLogic, ils se règlent dans la console d'administration, jamais dans l'application.
  • Une modification nécessite un redémarrage du serveur pour être appliquée — mais jamais une recompilation.
  • Les secrets saisis ici sont stockés en clair dans le fichier externe. En production, préférez les variables d'environnement ou un coffre à secrets.
